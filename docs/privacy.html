隱私權政策

生效日期：2026 年 10 月 4 日　・　適用版本：3.0.0 起

重點摘要

  • 開發者沒有自己的伺服器，不收集、不儲存、不出售你的任何資料，也沒有分析工具、廣告或追蹤程式。
  • 預設的「本機翻譯」使用 Chrome 內建翻譯，文字只在你的裝置上處理。
  • 只有在你選用「AI 模型」並親手按下翻譯（或選擇全頁翻譯）時，相關文字才會從你的瀏覽器直接送到你自己選的 AI 服務商，使用你自己的 API 金鑰。

壹適用範圍

本政策說明 Chrome 擴充功能「隨選翻譯 — Context Translator」（以下稱「本擴充功能」）如何處理資料。本擴充功能由 JAYlly CAT 以開放原始碼方式提供，原始碼公開在 GitHub，任何人都可以檢查以下說明是否屬實。

貳開發者不收集的資料

本擴充功能沒有帳號系統，也沒有任何屬於開發者的伺服器。開發者收不到：

  • 你瀏覽的網址、瀏覽紀錄或網頁內容；
  • 你選取或翻譯的文字、翻譯結果；
  • 你的 API 金鑰；
  • 使用統計、當機報告、裝置資訊或任何識別資料。

本擴充功能不使用 Cookie、不放廣告，也不載入任何第三方分析或追蹤程式。

參儲存在你瀏覽器裡的資料

為了記住你的設定，本擴充功能使用 Chrome 提供的 chrome.storage.sync 儲存下列資料。如果你在 Chrome 開啟了同步功能，這些資料會由 Google 同步到你登入同一帳號的其他電腦；開發者無法讀取。你也可以在設定勾選「金鑰只存在這台電腦」，API 金鑰就改存在 chrome.storage.local，不會同步。

使用全頁翻譯時，翻過的段落會暫存在該分頁的記憶體裡，讓你按「還原」後再翻不必重新送出；重新整理或關閉分頁就會清除，不會寫入硬碟。

你可以隨時在設定視窗清除 API 金鑰；移除本擴充功能時，Chrome 會一併刪除上述資料。

肆什麼時候會送出資料

本機翻譯（預設）

使用 Chrome 內建的翻譯與語言偵測功能，在你的裝置上完成。第一次翻譯某個語言時，Chrome 可能會從 Google 下載語言套件；這個下載由 Chrome 處理，不包含你要翻譯的文字。本擴充功能在這個模式下不會送出任何網頁內容。

AI 模型（選用，需你自己的 API 金鑰）

  • 選字翻譯：你按下「翻譯」時，選取的文字和它前後各約 200 字會送到你選的服務商，用來判斷詞義與上下文。
  • 全頁翻譯：你在右鍵選單選擇「全頁翻譯」後，畫面附近的段落會連同網頁標題分批送出；往下捲動時才會送出後面的段落。網站的選單、導覽列、頁首頁尾與側欄不會送出。
  • 不會送出網頁網址或 Cookie；全頁翻譯也不會送出輸入框裡的內容。
  • 資料從你的瀏覽器直接傳到服務商，不經過開發者；API 金鑰放在請求標頭中，只傳給對應的服務商。
  • 只有你親手操作時才會送出，網頁上的程式無法代替你觸發翻譯。

送出後，資料如何保存與使用，依各服務商的政策而定：

  • Google Gemini：Google 隱私權政策、Gemini API 附加條款
  • OpenAI：Privacy Policy
  • Anthropic（Claude）：Privacy Policy
  • DeepSeek：Privacy Policy
  • Kimi（Moonshot AI）：Kimi OpenPlatform Privacy Policy
  • MiniMax：Privacy Policy

提醒：依 Gemini API 附加條款，使用免費額度時，Google 可能用你送出的內容改進其產品，並可能由人員審閱。處理敏感內容時，建議使用付費方案，或改用本機翻譯。

伍權限說明

  • storage：保存上述設定與 API 金鑰。
  • contextMenus：在右鍵選單加入「全頁翻譯」。
  • activeTab、scripting：在你點選「全頁翻譯」的那一刻，若該分頁還沒載入本擴充功能（例如安裝前就開著的分頁），暫時把翻譯程式加到這一頁。只對你操作的分頁有效。
  • 網站存取（所有網站的內容腳本）：在你選取文字時顯示翻譯按鈕，並在你要求時翻譯網頁。網頁內容只在你的瀏覽器裡讀取，除非你選用 AI 模型並觸發翻譯，否則不會送出。
  • 本擴充功能只會連線到上列 AI 服務商的 API 網域。

陸Chrome 線上應用程式商店使用者資料政策

本擴充功能對使用者資料的使用，遵守 Chrome 線上應用程式商店使用者資料政策，包括「有限使用」（Limited Use）規定：資料只用來提供你所要求的翻譯功能；不出售；不轉移給第三方，除非是應你的要求送到你選的 AI 服務商；不用於廣告、信用評估或其他無關用途；開發者不會讀取這些資料。

柒兒童隱私

本擴充功能不是為 13 歲以下兒童設計，也不會在知情的情況下收集兒童的個人資料。

捌政策變更

如果資料處理方式有所改變，會更新本頁並修改上方的生效日期；重大變更也會寫在 GitHub 的版本說明中。

玖聯絡方式

對本政策有疑問，請在 GitHub Issues 提出。發現安全性問題，請透過 私下回報，不要公開張貼。

Privacy Policy

Effective date: October 4, 2026 · Applies to version 3.0.0 and later

Summary

  • The developer runs no servers and does not collect, store or sell any of your data. There are no analytics, ads or trackers.
  • The default on-device mode uses Chrome's built-in translation, so text is processed only on your device.
  • Only if you choose an AI model and then click Translate (or choose full-page translation) is the relevant text sent directly from your browser to the AI provider you picked, using your own API key.

1Scope

This policy explains how the Chrome extension “隨選翻譯 — Context Translator” (the “extension”) handles data. The extension is open source and published by JAYlly CAT; the code is on GitHub, so anyone can verify what is described here.

2What the developer does not collect

The extension has no accounts and no developer-operated servers. The developer never receives:

  • the pages you visit, your browsing history or page content;
  • the text you select or translate, or the translations;
  • your API keys;
  • usage statistics, crash reports, device information or any identifiers.

The extension sets no cookies, shows no ads and loads no third-party analytics or tracking code.

3Data stored in your browser

To remember your settings, the extension uses Chrome's chrome.storage.sync. If Chrome Sync is turned on, Google syncs this data to your other computers signed in to the same account; the developer cannot read it. If you tick “Keep keys on this computer only” in the settings, API keys are stored in chrome.storage.local instead and are not synced.

You can clear an API key in the settings window at any time. Removing the extension makes Chrome delete all of the data above.

4When data is sent

On-device translation (default)

Uses Chrome's built-in translation and language detection on your device. The first time you translate a language, Chrome may download a language pack from Google; Chrome handles that download and it does not contain the text you translate. In this mode the extension sends no page content anywhere.

AI models (optional, your own API key)

  • Selection translation: when you click Translate, the selected text and about 200 characters on each side of it are sent to the provider you chose, to resolve word sense and context.
  • Full-page translation: after you choose “全頁翻譯” (Translate full page) from the right-click menu, paragraphs near the visible area are sent in batches together with the page title; later paragraphs are sent only as you scroll to them. Site menus, navigation bars, site headers and footers, and sidebars are not sent.
  • Page URLs and cookies are never sent, and full-page translation skips form fields.
  • Requests go directly from your browser to the provider, never through the developer. Your API key is sent in a request header, only to the matching provider.
  • Nothing is sent unless you act; scripts on a web page cannot trigger a translation on your behalf.

Once sent, the data is governed by the provider's own policies:

  • Google Gemini: Google Privacy Policy, Gemini API Additional Terms
  • OpenAI: Privacy Policy
  • Anthropic (Claude): Privacy Policy
  • DeepSeek: Privacy Policy
  • Kimi (Moonshot AI): Kimi OpenPlatform Privacy Policy
  • MiniMax: Privacy Policy

Note: under the Gemini API Additional Terms, content sent on the free tier may be used by Google to improve its products and may be reviewed by people. For sensitive content, use a paid plan or on-device translation.

5Permissions

  • storage: saves the settings and API keys described above.
  • contextMenus: adds “全頁翻譯” (Translate full page) to the right-click menu.
  • activeTab, scripting: when you choose full-page translation on a tab where the extension is not loaded yet (for example, a tab opened before installation), the translation code is added to that one page. This applies only to the tab you act on.
  • Site access (content script on all sites): shows the Translate button when you select text and translates the page when you ask. Page content is read only inside your browser and is sent nowhere unless you use an AI model and trigger a translation.
  • The extension connects only to the API domains of the AI providers listed above.

6Chrome Web Store User Data Policy

The use of user data by this extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements: data is used only to provide the translation you request; it is not sold; it is not transferred to third parties except to the AI provider you chose, at your request; it is not used for advertising, creditworthiness or any unrelated purpose; and the developer does not read it.

7Children's privacy

The extension is not directed to children under 13 and does not knowingly collect personal information from children.

8Changes to this policy

If the way data is handled changes, this page and the effective date above will be updated; significant changes will also be noted in the release notes on GitHub.

9Contact

Questions about this policy can be raised in GitHub Issues. To report a security issue, please use private vulnerability reporting instead of posting publicly.
