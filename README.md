# 隨選翻譯 — Context Translator

一款輕巧的 Chrome 擴充功能。在任何網頁選取文字後，點一下旁邊出現的「翻譯」按鈕，即可從可拖曳的浮窗取得譯文；也可以在網頁上按右鍵選「全頁翻譯」，把整頁翻成你的語言。預設使用 Chrome 內建翻譯，不需要 API 金鑰。

## 功能特色

- **全頁翻譯**：在網頁空白處按右鍵 →「全頁翻譯」。譯文直接取代原文，也可切換成「對照」逐段並列原文與譯文，按「還原」恢復原樣。只翻譯畫面附近的段落，捲動時接著翻，之後動態載入的內容也會自動翻譯；程式碼與輸入框不會被翻譯；譯成中文時，本來就是中文的段落也會略過。全頁翻譯一律使用 Chrome 內建翻譯，在裝置上完成。
- **免金鑰翻譯**：Chrome 138 以上的桌面版可在裝置上下載語言套件並直接翻譯。
- **資料留在裝置上**：使用 Chrome 內建翻譯時，選取內容不會送到遠端模型。
- **進階上下文翻譯**：選用外部模型時，會連同選取文字所在段落分析，減少單字多義與指代錯誤。
- **紙本字典風介面**：米白紙色、襯線字體、墨線分隔，搭配朱紅「文」字印章。浮窗像查字典一樣排版：顯示原文、譯文、語言方向與使用中的引擎；查單字時會列出編號釋義與語境說明。支援夜讀（深色）模式、高對比、減少動態效果，並隔離網頁本身的 CSS，避免版面被網站樣式弄亂。
- **可拖曳結果視窗**：拖曳頂部即可移動，位置會自動限制在可見範圍內。
- **多模型支援**：外部模型為選配，且每個服務商分開保存 API 金鑰。
  - Google Gemini（`gemini-2.0-flash`）
  - MiniMax（`MiniMax-M2.5`）
  - Kimi / Moonshot（`moonshot-v1-8k`）
  - OpenAI（`gpt-4o-mini`）
  - DeepSeek（`deepseek-v4-flash`，關閉思考模式以降低延遲與用量）
  - Claude / Anthropic（`claude-haiku-4-5`）
- **多種譯文語言**：繁體中文、簡體中文、英文、韓文、法文、德文與西班牙文。
- **操作便利**：設定即時儲存；API 金鑰按「儲存」（或 Enter）才會寫入，避免打到一半就生效。一鍵複製譯文、`Esc` 關閉，以及每日使用量統計。
- **無障礙支援**：完整的鍵盤焦點、狀態提示與輔助技術標籤。

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `manifest.json` | Chrome Manifest V3 設定 |
| `background.js` | 模型 API 路由與提示詞、右鍵「全頁翻譯」選單 |
| `content.js` | 網頁選字、翻譯按鈕、結果浮窗與拖曳互動；全頁翻譯與底部狀態列 |
| `popup.html` / `popup.js` | 翻譯引擎、API 金鑰（按儲存才寫入）、譯文語言與功能開關設定 |
| `icons/` | 擴充功能與工具列圖示（16、32、48、128px） |

## 安裝

1. 在 Chrome 開啟 `chrome://extensions/`。
2. 開啟右上角的「開發人員模式」。
3. 點選「載入未封裝項目」，並選擇本專案資料夾。
4. 點擊工具列圖示並確認翻譯引擎。預設的「本機翻譯」使用 Chrome 內建翻譯，不需要填寫 API 金鑰。

## 使用方式

1. 在任意網頁選取要翻譯的文字。
2. 點擊選取範圍旁出現的「翻譯」按鈕。
3. 在結果浮窗查看譯文；可拖曳頂部移動，或使用複製與關閉按鈕。

### 全頁翻譯

1. 在網頁上按右鍵，選「全頁翻譯」。
2. 第一次翻譯某個語言時，底部狀態列會請你按「下載並翻譯」，下載語言套件後就會開始翻譯，之後不用再下載。
3. 狀態列可切換「譯文」與「對照」，按「還原」恢復原文，按 × 收起狀態列。

## 選配的 API 金鑰

只有在設定視窗切換到「AI 模型」時才需要 API 金鑰，金鑰欄位旁的「取得金鑰」會直接開啟所選服務商的申請頁面。貼上金鑰後按「儲存」（或 Enter）才會生效；換到別的服務商時，還沒儲存的輸入會被捨棄。這些模型可提供更完整的上下文說明；尚未填入金鑰時，翻譯會暫時使用 Chrome 內建翻譯。

| 服務商 | 申請位置 |
|---|---|
| Gemini | https://aistudio.google.com/app/apikey |
| MiniMax | https://platform.minimaxi.com/ |
| Kimi | https://platform.moonshot.cn/ |
| OpenAI | https://platform.openai.com/api-keys |
| DeepSeek | https://platform.deepseek.com/ |
| Claude | https://console.anthropic.com/ |

API 金鑰只會儲存在 `chrome.storage.sync`，不會傳送給所選模型服務商以外的第三方。

## 隱私與安全

- **本機翻譯**：文字只在你的裝置上處理，不會送出。
- **全頁翻譯**：一律使用 Chrome 內建翻譯，即使選了 AI 模型也一樣，整頁內容不會送到任何服務商。
- **AI 模型**：按下「翻譯」時，選取的文字連同所在段落（最多約 2,000 字）會送到你選擇的服務商，並受該服務商的隱私政策約束。在網路銀行、私人郵件、公司內部文件等敏感頁面，建議改用本機翻譯。
- **只在你親手點擊時送出**：網頁上的程式無法代替你按下翻譯按鈕，因此無法用你的金鑰送出請求。
- **API 金鑰**：存放在 `chrome.storage.sync`，會隨 Chrome 同步到你的 Google 帳號；請求時放在 HTTP 標頭中，只傳給對應的服務商。
- **權限**：
  - `storage`：保存設定與金鑰。
  - `contextMenus`：在右鍵選單加入「全頁翻譯」。
  - `activeTab` + `scripting`：安裝或更新擴充功能前就已開啟的分頁還沒有內容腳本，按下「全頁翻譯」時才把翻譯程式注入到「目前這一頁」。`activeTab` 只在你親手點選選單後、對該分頁暫時有效，不會讓擴充功能讀取其他分頁。
  - 內容腳本在所有網頁上注入選字按鈕；背景程式只能連線到上表列出的 API 網域。

發現安全性問題時，請在 GitHub 以私下回報（Security → Report a vulnerability）的方式聯絡，不要開公開 issue。

## 常見問題

**沒有出現翻譯按鈕？**

重新載入擴充功能後，請刷新原本已開啟的網頁，並確認「選字翻譯」開關為開啟狀態。

**擴充功能更新後無法翻譯？**

刷新目前頁面，讓最新版的內容腳本重新載入。

**右鍵選單沒有「全頁翻譯」？**

到 `chrome://extensions/` 重新載入擴充功能；選單在安裝或更新時建立。在輸入框或選取文字上按右鍵不會出現，請在網頁空白處按右鍵。

**全頁翻譯一直停在下載？**

語言套件由 Chrome 下載，需要網路連線；如果超過一分鐘沒有進度，狀態列會顯示「再試一次」。

**翻譯失敗？**

- Chrome 內建翻譯需要桌面版 Chrome 138 以上；首次使用時需連線下載語言套件。
- 若使用外部模型，請確認目前模型與 API 金鑰相符。
- 檢查網路、API 額度與帳號餘額。
- Claude 從瀏覽器直接呼叫時，需要帳號允許瀏覽器存取。
