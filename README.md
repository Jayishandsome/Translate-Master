# 隨選翻譯 — Context Translator

一款輕巧的 Chrome 擴充功能。在任何網頁選取文字後，點一下旁邊出現的「翻譯」按鈕，即可從可拖曳的浮窗取得譯文；也可以在網頁上按右鍵選「全頁翻譯」，把整頁翻成你的語言。預設使用 Chrome 內建翻譯，不需要 API 金鑰。

## 功能特色

- **全頁翻譯**：在網頁空白處按右鍵 →「全頁翻譯」。譯文直接取代原文，也可切換成「對照」逐段並列原文與譯文，按「還原」恢復原樣。只翻譯畫面附近的段落，捲動時接著翻，之後動態載入的內容也會自動翻譯；程式碼與輸入框不會被翻譯；譯成中文時，本來就是中文的段落也會略過。翻譯引擎跟著設定走：本機翻譯在裝置上完成；選了 AI 模型（並已儲存金鑰）就由該模型翻譯，相鄰段落一批送出，譯文能參考前後文。AI 模式會略過選單、導覽列、網站頁首頁尾與側欄，重複出現的同一段文字只送一次；同一頁翻過的段落會記住，按「還原」後再翻不會重新收費（重新整理頁面後清空）。
- **全頁翻譯保留連結**：「譯文」模式下，段落裡的連結一樣點得到；整段就是連結的標題或選單，譯文直接放在連結裡。
- **混合語言的頁面**：本機全頁翻譯逐段偵測語言，英文頁裡夾著的日文段落會用日文去翻。
- **免金鑰翻譯**：Chrome 138 以上的桌面版可在裝置上下載語言套件並直接翻譯。
- **資料留在裝置上**：使用 Chrome 內建翻譯時，選取內容不會送到遠端模型。
- **進階上下文翻譯**：選用外部模型時，會連同選取處前後約 200 字一起分析，減少單字多義與指代錯誤。
- **紙本字典風介面**：米白紙色、襯線字體、墨線分隔，搭配朱紅「文」字印章。浮窗像查字典一樣排版：顯示原文、譯文、語言方向與使用中的引擎；查單字時會列出編號釋義與語境說明。支援夜讀（深色）模式、高對比、減少動態效果，並隔離網頁本身的 CSS，避免版面被網站樣式弄亂。
- **可拖曳結果視窗**：拖曳頂部即可移動，位置會自動限制在可見範圍內。
- **多模型支援**：外部模型為選配，且每個服務商分開保存 API 金鑰。每家都用目前最便宜、仍在服務的模型，並把「思考」關掉或壓到最低，翻譯更快也更省。
  - Google Gemini（`gemini-3.5-flash-lite`，思考設為 minimal）
  - OpenAI（`gpt-6-luna`，推理設為 none）
  - Claude / Anthropic（`claude-haiku-4-5-20251001`）
  - DeepSeek（`deepseek-flash`，關閉思考）
  - Kimi / Moonshot（`kimi-k2.6`，關閉思考；中國站與國際站的金鑰都能用）
  - MiniMax（`MiniMax-M3`，關閉思考；國際站與中國站的金鑰都能用）
- **多種譯文語言**：繁體中文、簡體中文、英文、日文、韓文、法文、德文、西班牙文、葡萄牙文、義大利文、俄文、越南文、泰文、印尼文。
- **多語系介面**：介面跟著 Chrome 的語言顯示繁體中文、簡體中文或英文。
- **模型停用也不怕**：服務商停用預設模型時會直接說明原因，也可以在設定的「進階」自己填模型名稱，不必等新版。
- **金鑰可以只存本機**：可選擇讓 API 金鑰只存在這台電腦，不跟著 Chrome 同步。
- **安裝說明頁**：第一次安裝會打開說明頁，教用法、檢查這台電腦的 Chrome 能不能用本機翻譯，還能直接試用。
- **操作便利**：設定即時儲存；API 金鑰按「儲存」（或 Enter）才會寫入，避免打到一半就生效。一鍵複製譯文、`Esc` 關閉，以及每日使用量統計。
- **無障礙支援**：完整的鍵盤焦點、狀態提示與輔助技術標籤。

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `manifest.json` | Chrome Manifest V3 設定 |
| `background.js` | 模型 API 路由與提示詞、全頁翻譯的分批請求、右鍵選單 |
| `src/content/` | 內容腳本的原始碼（選字、浮窗、全頁翻譯等），由 `npm run build` 合併成 `content.js` |
| `content.js` | 產生出來的內容腳本，請勿直接修改 |
| `src/locales.json` | 所有介面文字（繁中、簡中、英文），由 `npm run build` 產生 `_locales/` |
| `popup.html` / `popup.js` | 設定視窗 |
| `welcome.html` / `welcome.js` | 安裝後的說明頁 |
| `tests/` | Playwright 自動測試（替身環境與真正載入的擴充功能） |
| `docs/` | GitHub Pages：隱私權政策 |
| `store/` | Chrome 線上應用程式商店的上架資料與圖片 |
| `icons/` | 擴充功能與工具列圖示（16、32、48、128px） |

## 安裝

1. 在 Chrome 開啟 `chrome://extensions/`。
2. 開啟右上角的「開發人員模式」。
3. 點選「載入未封裝項目」，並選擇本專案資料夾。
4. 點擊工具列圖示並確認翻譯引擎。預設的「本機翻譯」使用 Chrome 內建翻譯，不需要填寫 API 金鑰。

## 開發

```bash
npm install
npm run build      # 合併 src/content/ → content.js，產生 _locales/
npm test           # 跑全部 Playwright 測試（需要 npx playwright install chromium）
npm run package    # 打包上架用的 zip 到 dist/
```

修改內容腳本請改 `src/content/` 裡的檔案，修改介面文字請改 `src/locales.json`，再執行 `npm run build`。每次推到 GitHub，GitHub Actions 會檢查產生的檔案是否最新並跑完所有測試。

## 使用方式

1. 在任意網頁選取要翻譯的文字。
2. 點擊選取範圍旁出現的「翻譯」按鈕。
3. 在結果浮窗查看譯文；可拖曳頂部移動，或使用複製與關閉按鈕。

### 全頁翻譯

1. 在網頁上按右鍵，選「全頁翻譯」。
2. 使用本機翻譯時，第一次翻譯某個語言，底部狀態列會請你按「下載並翻譯」，下載語言套件後就會開始翻譯，之後不用再下載。使用 AI 模型時不需要這一步。
3. 狀態列可切換「譯文」與「對照」，按「還原」恢復原文，按 × 收起狀態列。

## 選配的 API 金鑰

只有在設定視窗切換到「AI 模型」時才需要 API 金鑰，金鑰欄位旁的「取得金鑰」會直接開啟所選服務商的申請頁面。貼上金鑰後按「儲存」（或 Enter）才會生效；換到別的服務商時，還沒儲存的輸入會被捨棄。這些模型可提供更完整的上下文說明；尚未填入金鑰時，翻譯會暫時使用 Chrome 內建翻譯。

| 服務商 | 申請位置 |
|---|---|
| Gemini | https://aistudio.google.com/app/apikey |
| OpenAI | https://platform.openai.com/api-keys |
| Claude | https://console.anthropic.com/ |
| DeepSeek | https://platform.deepseek.com/ |
| Kimi | 國際站 https://platform.kimi.ai/ ・中國站 https://platform.kimi.com/ |
| MiniMax | 國際站 https://platform.minimax.io/ ・中國站 https://platform.minimax.cn/ |

API 金鑰預設存在 `chrome.storage.sync`；勾選「金鑰只存在這台電腦」就改存 `chrome.storage.local`。金鑰不會傳送給所選模型服務商以外的第三方。

服務商停用預設模型時，可以在設定的「進階」填入新的模型名稱；留空就用預設模型。

## 隱私與安全

- **本機翻譯**：文字只在你的裝置上處理，不會送出。
- **全頁翻譯**：本機翻譯時完全不送出。選了 AI 模型時，畫面附近的段落會連同網頁標題分批送到你選的服務商，往下捲才會送出後面的段落，不會一次把整頁送出；選單、導覽列、網站頁首頁尾與側欄不會送出。每一批都會消耗你的 API 額度。
- **AI 模型**：按下「翻譯」時，選取的文字連同前後各約 200 字會送到你選擇的服務商，並受該服務商的隱私政策約束。在網路銀行、私人郵件、公司內部文件等敏感頁面，建議改用本機翻譯。
- **只在你親手點擊時送出**：網頁上的程式無法代替你按下翻譯按鈕，因此無法用你的金鑰送出請求。
- **API 金鑰**：預設存放在 `chrome.storage.sync`，會隨 Chrome 同步到你的 Google 帳號；也可以選擇只存在這台電腦。請求時放在 HTTP 標頭中，只傳給對應的服務商。
- **權限**：
  - `storage`：保存設定與金鑰。
  - `contextMenus`：在右鍵選單加入「全頁翻譯」。
  - `activeTab` + `scripting`：安裝或更新擴充功能前就已開啟的分頁還沒有內容腳本，按下「全頁翻譯」時才把翻譯程式注入到「目前這一頁」。`activeTab` 只在你親手點選選單後、對該分頁暫時有效，不會讓擴充功能讀取其他分頁。
  - 內容腳本在所有網頁上注入選字按鈕；背景程式只能連線到上表列出的 API 網域。

完整的隱私權政策：https://jayishandsome.github.io/Translate-Master/privacy.html

發現安全性問題時，請在 GitHub 以私下回報（Security → Report a vulnerability）的方式聯絡，不要開公開 issue。

## 常見問題

**沒有出現翻譯按鈕？**

重新載入擴充功能後，請刷新原本已開啟的網頁，並確認「選字翻譯」開關為開啟狀態。

**擴充功能更新後無法翻譯？**

刷新目前頁面，讓最新版的內容腳本重新載入。

**右鍵選單沒有「全頁翻譯」？**

到 `chrome://extensions/` 重新載入擴充功能；選單在安裝或更新時建立。在輸入框或選取文字上按右鍵不會出現，請在網頁空白處按右鍵。

**全頁翻譯顯示「翻譯失敗」？**

使用 AI 模型時，狀態列會顯示服務商回傳的錯誤（例如金鑰無效、額度用完）。額度或忙碌這類暫時性錯誤會自動再試一次；其他錯誤修正後按「重試」即可。

**全頁翻譯一直停在下載？**

語言套件由 Chrome 下載，需要網路連線；如果超過一分鐘沒有進度，狀態列會顯示「再試一次」。

**翻譯失敗？**

- Chrome 內建翻譯需要桌面版 Chrome 138 以上；首次使用時需連線下載語言套件。
- 若使用外部模型，請確認目前模型與 API 金鑰相符；錯誤訊息說模型已停用時，到設定的「進階」改填模型名稱。
- 檢查網路、API 額度與帳號餘額。
- Claude 從瀏覽器直接呼叫時，需要帳號允許瀏覽器存取。
